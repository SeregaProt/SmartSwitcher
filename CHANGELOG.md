## [0.4.0] — 2026-10-28

План доработок по итогам аудита кода — [docs/ROADMAP.md](docs/ROADMAP.md).

### Исправлено
- Double-Shift после клика, стрелок, Esc или смены приложения удалял символы
  в новом месте курсора — последнее слово теперь забывается вместе с контекстом.
- Double-Shift после Enter/Tab съедал перевод строки и часть слова
  (`ghbdtn⏎` → `gпривет`); автозамена на Enter делала то же самое.
- Ручное исправление работало на паузе, в исключённых приложениях и в полях
  паролей.
- Лицензия: `isDevBuild` сравнивал ключ сам с собой — Pro оставался открытым
  и с настоящим ключом; Pro-функции теперь действительно закрыты.
- Гонки данных: движок читал массивы настроек одновременно с записью из UI
  (теперь — потокобезопасный снимок); дневник читал флаг с чужого потока.
- Буфер не сбрасывался, когда система отключала event tap или менялось
  активное приложение; Backspace после цифры стирал в буфере не тот символ.
- Accessibility-запросы без таймаута могли остановить движок на 6 секунд.
- Вставка по 16 символов в событии ломалась в Electron/Java-приложениях и
  разрывала эмодзи — теперь посимвольно.
- Обработчик фатальных сигналов не был async-signal-safe.
- Entitlements: iCloud-ключ без provisioning profile не дал бы релизу
  запуститься; `release.sh` встраивает профиль, если он передан.
- CI на macos-14 не мог собрать пакет со swift-tools 6.0.

### Добавлено
- Триграммная символьная модель: recall на словах вне словаря ~50% → 90/83%.
- Контекст фразы: однобуквенные слова (`d` → `в`), мягкие пороги; Caps Lock.
- Маппинг по реально установленным раскладкам (`UCKeyTranslate`).
- Личный словарь на солёных хешах (положительное самообучение).
- Режимы приложений: авто / только вручную / выключено.
- Хоткеи для выделения: ⌃⌥K / ⌃⌥U / ⌃⌥T.
- HUD раскладки у курсора, статистика исправлений (только счётчики).
- Надёжный режим (ADR-0008): придерживание ввода на время перенабора и
  исправление слова перед Enter; откат Backspace'ом (opt-in).
- Синхронизация: слияние списков слов (LWW-element-set), включение без
  перезапуска, флаг «включено» не синхронизируется, без пинг-понга.
- Проверка обновлений через GitHub Releases (`SSGitHubRepository`).
- Настройки с боковой навигацией, разделы «Приложения» и «Статистика».
- Честные метрики: отложенная выборка `eval_*_oov`; 272 проверки и 12
  интеграционных сценариев.

### Изменено
- Swift 6 language mode для SmartSwitcherKit, 0 предупреждений.
- Сборка через Xcode (`DEVELOPER_DIR` в Makefile).
- Терминалы по умолчанию — «только вручную» вместо полного исключения.
- Удалён код фазы 1: `HeuristicDetector`, обёртка `DoubleShiftDetector`.

## [0.3.0] — 2026-06-13

### Добавлено
- **FR-4** хоткеи: Single-Shift (смена раскладки, опционально), настраиваемые
  жесты, отдельный тумблер отката, окно двойного нажатия. Движок переведён на
  серийную очередь обработки событий (низкая латентность, без гонок).
- **FR-7** автозамена текста: правила «сокращение → текст» с сохранением
  регистра, вкладка «Автозамена».
- **FR-8** ненавязчивые уведомления при переключении (выкл по умолчанию).
- Новые вкладки настроек: **Языки** (активные раскладки детекта), **Хоткеи**,
  **Автозамена**, **Обновления** (канал стабильный/бета, авто-проверка),
  **Аккаунт/Лицензия**.
- Пошаговый **онбординг-мастер** (4.4): приветствие, выдача прав с живым
  статусом, выбор языков, тур по хоткеям.
- **SyncService** (15): синхронизация настроек через iCloud KVS,
  last-write-wins, только настройки — никогда текст (ADR-0007).
- **LicenseService** (22): офлайн-проверка лицензионных ключей (Ed25519),
  хранение в Keychain, восстановление покупок, open-core гейтинг.
- **CrashGuard** (12): глобальный перехват исключений и сигналов в приватный
  лог без набранного текста.
- Иконка приложения, `.swiftlint.yml`, SBOM, шаблоны issue, сайт (лендинг +
  страница «Приватность»), скрипт нотаризации, регламент поддержки.

### Изменено
- iTerm убран из исключений по умолчанию; Terminal.app остаётся исключённым.
- Детектор учитывает активные языки (гейтинг по настройкам «Языки»).

### Исправлено
- Надёжность переключения раскладки на уровне системы: реальная текущая
  раскладка читается на главном потоке перед сменой, а не из кеша
  (distributed-уведомление могло потеряться и оставить кеш неверным — тогда
  система не переключалась, и приходилось исправлять каждое слово отдельно).
  Интеграционный тест проверяет фактическую смену системной раскладки.
- Краш (SIGTRAP) при первом же авто-исправлении: TIS-вызовы раскладки
  выполнялись на фоновом потоке event tap, что нарушало требование HIToolbox
  о главном потоке (`dispatch_assert_queue`). `LayoutController` теперь
  кеширует текущую раскладку по системному уведомлению и маршалит смену на
  главный поток; `AppExclusionManager` кеширует активное приложение по
  `NSWorkspace.didActivateApplication` вместо чтения с фонового потока.
  Добавлен регрессионный тест.

## [0.2.0] — 2026-06-13

### Добавлено
- Статистический детектор (фаза 2): словари top-9000 слов RU/EN и биграммные
  log-вероятностные модели с маркерами границ слова; метрики на корпусе:
  recall 96–99%, ложные срабатывания 0,05% на словах вне словаря.
- Правила слов: списки «никогда не исправлять» и «всегда исправлять» (FR-5),
  самообучение пишет в «никогда» (FR-6).
- Дневник исправлений (FR-11): выключен по умолчанию, AES-GCM шифрование,
  ключ в Keychain, очистка одной кнопкой.
- Импорт/экспорт конфигурации в JSON с валидацией (раздел 24).
- Локализация интерфейса RU/EN (раздел 18).
- Детект конкурирующих перехватчиков клавиатуры с предупреждением (раздел 21).
- Кнопка «Очистить локальные данные» (раздел 4.3).
- Пункт меню «Проверить обновления» (заглушка до интеграции Sparkle).
- Оценочный стенд качества детектора и бенчмарк латентности в CI-наборе.

### Изменено
- Основной детектор — `StatisticalDetector`; эвристический остался как
  резервный при отсутствии ресурсов.
- Настройки: новые вкладки «Слова», «Дневник», расширенная «Приватность».

## [0.1.0] — 2026-06-13

### Добавлено
- Каркас menu bar приложения (фаза 0): CGEventTap (listen-only), онбординг
  прав Accessibility, переподключение tap при отключении системой.

- Double-Shift: ручное исправление последнего слова и откат авто-исправления.
- Исключения приложений (терминалы, менеджеры паролей — по умолчанию).
- Игнорирование secure text fields (поля паролей).
- Собственный тест-раннер (106 проверок) — работает без Xcode.
