# SmartSwitcher

Автоматический переключатель раскладки клавиатуры для macOS — современный аналог Punto Switcher. Нативный (Swift, Apple Silicon + Intel), приватный: набранный текст никогда не покидает устройство.

Набрали `ghbdtn` вместо `привет`? SmartSwitcher заметит это на границе слова, удалит «мусор», перенаберёт слово правильно и переключит раскладку. Работает в обе стороны (`руддщ` → `hello`).

**Статус:** v0.4 — все FR-1…FR-11 и план доработок ([ROADMAP](docs/ROADMAP.md), [CHANGELOG](CHANGELOG.md)).

## Качество детектора

Регрессионный стенд (обязательный gate CI): словарные слова и **отложенная
выборка** — слова, которых нет ни в словаре, ни в обучении модели.

| Метрика | Цель (ТЗ 7.2) | Фактически |
|---|---|---|
| Recall, словарные слова RU / EN | > 90% | **98,7% / 99,6%** |
| Recall вне словаря RU / EN | — | **89,9% / 82,8%** (в контексте фразы 93,5% / 89,3%) |
| Ложные срабатывания вне словаря | минимум | **0,17% / 0,30%** |
| Ложные срабатывания, частотные слова | 0 | **0** |
| Время анализа слова | < 5 мс | **0,008 мс** |

## Быстрый старт

Требования: macOS 13+, Xcode 16+ (Swift 6).

```bash
make bundle        # сборка dist/SmartSwitcher.app (release)
open dist/SmartSwitcher.app
```

При первом запуске выдайте права **Universal Access (Accessibility)**:
Системные настройки → Конфиденциальность и безопасность → Universal Access → включить SmartSwitcher. Подробнее — [руководство пользователя](docs/USER_GUIDE.md).

## Возможности

- **Авто-исправление** на границе слова со сменой раскладки и перенабором; precision-first: числа, URL, пути, идентификаторы, аббревиатуры не трогаются.
- **Статистический «мозг»**: словари top-9000 слов RU/EN + триграммная символьная модель ([формат](docs/DICTIONARIES.md)); **контекст фразы** (однобуквенные слова, мягкие пороги), **Caps Lock**.
- **Любые раскладки macOS**: «Русская» и «Русская – ПК», ABC, British, Dvorak, Colemak — таблицы по установленным раскладкам.
- **Личный словарь**: слова, которые вы набираете и оставляете, перестают исправляться (хранятся только хеши).
- **Double-Shift** — ручное исправление последнего слова и откат авто-исправления; откат запоминается (**самообучение**).
- **Хоткеи для выделения**: ⌃⌥K раскладка, ⌃⌥U регистр, ⌃⌥T транслит.
- **Надёжный режим** (opt-in): ввод придерживается на время перенабора, слово перед Enter тоже исправляется ([ADR-0008](docs/adr/0008-reliable-mode.md)).
- **Режимы приложений**: авто / только вручную (терминалы) / выключено (менеджеры паролей); поля паролей и secure input игнорируются всегда.
- **HUD у курсора**, **статистика** (только счётчики), откат Backspace (opt-in).
- **Дневник исправлений** (выключен по умолчанию): локально, AES-GCM, ключ в Keychain, очистка одной кнопкой.
- **Импорт/экспорт** настроек в JSON — перенос между Mac, бэкап.
- **Локализация** интерфейса: русский, английский.
- **Детект конфликтов** с другими перехватчиками клавиатуры (Karabiner и т.п.) с предупреждением в меню.
- **Menu bar UI** + настройки SwiftUI с боковой навигацией, автозапуск, пауза на 10 минут, проверка обновлений через GitHub Releases.
- **Pro** (лицензионный ключ): синхронизация через iCloud со слиянием списков слов, автозамена текста.

## Команды разработки

```bash
make build             # сборка пакета
make test              # тесты + метрики качества + бенчмарк (272 проверки)
make integration       # настоящий движок печатает в своё окно (12 сценариев)
make bundle            # release .app для текущей архитектуры
make bundle-universal  # universal binary (arm64 + x86_64)
make run               # собрать и запустить
```

## Приватность

Privacy by design (ТЗ, раздел 11): обработка только в памяти; ноль сетевой передачи набранного текста; логи без текста; дневник — opt-in, шифруется, очищается. Сетевые операции приложения исчерпываются проверкой обновлений по явному действию пользователя.
