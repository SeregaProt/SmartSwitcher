# Руководство пользователя SmartSwitcher

## Установка

1. Соберите приложение: `make bundle` (нужен Xcode: Command Line Tools с SDK
   macOS 27 не собирают SwiftUI).
2. Откройте `dist/SmartSwitcher.app`. Приложение живёт в строке меню
   (иконка с текущей раскладкой: EN/RU), в Dock не появляется.

## Выдача прав (обязательно)

SmartSwitcher слушает клавиатуру через системный API Accessibility:

1. При первом запуске появится диалог — нажмите «Открыть настройки».
2. Системные настройки → Конфиденциальность и безопасность → Universal Access
   (Accessibility) → включите SmartSwitcher.
3. Движок стартует автоматически, иконка ⚠️ сменится на индикатор раскладки.

> После пересборки приложения macOS может потребовать выдать права заново —
> это особенность ad-hoc подписи (до перехода на Developer ID).

## Как это работает

Печатайте как обычно. Когда вы заканчиваете слово (пробел и другие
разделители), SmartSwitcher оценивает его:

- `ghbdtn ` → мгновенно станет `привет `, раскладка переключится на русскую;
- `руддщ ` → станет `hello `, раскладка переключится на английскую;
- осмысленные слова, числа, адреса, пути, команды, идентификаторы —
  не трогаются.

Ещё SmartSwitcher учитывает контекст: после русских слов `d` станет `в`,
а слово, набранное с включённым Caps Lock (`GHBDTN`), станет `ПРИВЕТ`.
Слова, которые вы часто набираете и оставляете как есть, попадают в личный
словарь и больше не исправляются (хранятся только хеши слов).

После Enter и Tab слово автоматически не исправляется (чтобы не редактировать
уже отправленное сообщение) — кроме **надёжного режима** (включён по
умолчанию): в нём слово исправляется до отправки.

## Хоткеи

| Жест | Действие |
|---|---|
| **Shift, Shift** (двойное нажатие) | Исправить раскладку текущего/последнего слова. Также откатывает только что сделанное авто-исправление — и приложение запоминает слово, чтобы больше его не трогать. |
| **⌃⌥K** | Сменить раскладку выделенного текста |
| **⌃⌥U** | Инвертировать регистр выделенного текста (`пРИВЕТ` → `Привет`) |
| **⌃⌥T** | Транслитерировать выделенный текст (`Щука` ↔ `Shchuka`) |
| **Backspace** сразу после исправления | Отменить исправление (включается в настройках) |

## Меню

- **Пауза / Включить** — выключить авто-исправление полностью.
- **Приостановить на 10 минут** — временная пауза.
- **Настройки…** — все параметры (см. ниже).
- **Проверить обновления…** — сверяет версию с GitHub Releases.

## Настройки

- **Общие**: автокоррекция, личный словарь, надёжный режим, индикатор у
  курсора, звук, автозапуск, синхронизация через iCloud (Pro), экспорт/импорт
  конфигурации (JSON — для переноса на другой Mac или бэкапа).
- **Приложения**: «только вручную» (по умолчанию терминалы — работает
  Double-Shift, но не авто-исправление) и «выключено полностью» (менеджеры
  паролей). Добавьте сюда игры и IDE, если мешает.
- **Статистика**: сколько исправлений и сэкономленных нажатий — только
  счётчики, без слов.
- **Слова**: «Никогда не исправлять» (имена, никнеймы, термины — сюда же
  попадают слова после отката Double-Shift'ом) и «Всегда исправлять».
- **Дневник**: история исправлений. Выключен по умолчанию; хранится только
  локально и в зашифрованном виде; очищается одной кнопкой.
- **Приватность**: статус обработки данных, очистка личного словаря,
  статистики и всех локальных данных.

## Приватность

- Набранный текст обрабатывается только в оперативной памяти этого Mac.
- В сеть не передаётся ничего и никогда.
- Поля паролей игнорируются автоматически (по системному признаку secure
  text field).
- Логи приложения не содержат набранный текст — только факты решений.

## Известные ограничения (FAQ)

- **Слово перед Enter не исправилось.** Проверьте, что надёжный режим включён
  (Настройки → Общие): Enter придерживается на миллисекунды, пока слово
  исправляется. Без него исправлять «сквозь» Enter опасно.
- **Хочу, чтобы SmartSwitcher никогда не задерживал ввод.** Выключите надёжный
  режим — останется только наблюдение за клавиатурой; при очень быстром наборе
  исправление тогда может перемешаться со следующим словом.
- **Другая русская раскладка («Русская» вместо «Русская – ПК») или Dvorak.**
  Поддерживается: таблицы строятся по установленным раскладкам.
- **В игре/нестандартном приложении исправление печатает мусор.** Добавьте
  приложение в Исключения — некоторые программы игнорируют системные события
  вставки текста.
- **CJK/IME-раскладки.** Не поддерживаются в детекте; приложение в их
  присутствии не вмешивается в ввод.
- **Иконка показывает ⚠️.** Нет прав Accessibility — выдайте их (см. выше).
