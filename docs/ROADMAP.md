# План доработок SmartSwitcher (v0.4)

Источник: аудит кода от 2026-10-21. Статусы: ☐ — не начато, ☑ — сделано,
⧗ — требует внешних ресурсов (Developer ID, домен, хостинг).
Все кодовые пункты выполнены 2026-10-28 (v0.4.0, см. CHANGELOG).

## Этап 1. Фундамент
- ☑ 1.1 Git-репозиторий, базовый коммит.
- ☑ 1.2 Сборка через полный Xcode (`DEVELOPER_DIR`) в Makefile; CLT с SDK 27
  не собирает SwiftUI (`@State` — макрос без плагина в CLT).
- ☑ 1.3 Удалить мёртвый код фазы 1 (`HeuristicDetector`, `DoubleShiftDetector`),
  перевести их тесты на актуальные компоненты.
- ☑ 1.4 Отложенная выборка для честных метрик; проверка обновлений через
  GitHub Releases репозитория SeregaProt/SmartSwitcher.

## Этап 2. Критические баги (P0)
- ☑ 2.1 `lastCommitted` сбрасывается вместе с контекстом курсора (клик,
  навигация, Esc, смена приложения, Backspace за границу слова).
- ☑ 2.2 Enter/Tab запоминаются с реальным разделителем (`\n`, `\t`) —
  Double-Shift после Enter больше не съедает перевод строки.
- ☑ 2.3 Ручное исправление уважает паузу, режим приложения и поля паролей.
- ☑ 2.4 Лицензия: `isDevBuild` сравнивает с плейсхолдером, а не с самим собой;
  Pro-функции реально закрыты `proFeaturesUnlocked`.
- ☑ 2.5 Потокобезопасный снимок настроек для движка (нет гонок на массивах).
- ☑ 2.6 Сброс буфера при отключении tap системой и при смене приложения.
- ☑ 2.7 Таймаут Accessibility-запросов + `IsSecureEventInputEnabled()`.
- ☑ 2.8 Раскладка переключается ДО перенабора; посимвольная вставка
  (совместимость с Electron/Java, без разрыва суррогатных пар).
- ☑ 2.9 Entitlements: iCloud-ключ только при наличии provisioning profile.

## Этап 3. Качество распознавания
- ☑ 3.1 Маппинг раскладок по реальным данным клавиатуры (`UCKeyTranslate`) —
  «Русская» (Apple), «Русская – ПК», British, Dvorak, Colemak и т.д.;
  статическая таблица остаётся фолбэком.
- ☑ 3.2 Контекст фразы: язык предыдущих слов как сигнал; однобуквенные слова
  (в, я, к, с, и, у, о, а / a, i); набор с Caps Lock.
- ☑ 3.3 Триграммная модель (интерполяция с биграммами).
- ☑ 3.4 Личный словарь: слова, которые пользователь набирает и оставляет,
  перестают исправляться (положительное самообучение).
- ☑ 3.5 Честные метрики: recall на словах вне словаря и на фразах.

## Этап 4. Возможности продукта
- ☑ 4.1 Откат исправления Backspace сразу после замены (как в Punto).
- ☑ 4.2 Горячие клавиши для выделения: сменить раскладку, регистр,
  транслитерировать.
- ☑ 4.3 HUD-индикатор у курсора при исправлении.
- ☑ 4.4 Исправление слова перед Enter (активный tap, включён по умолчанию) —
  объединено с придерживанием ввода в «надёжный режим» (ADR-0008).
- ☑ 4.5 Режимы приложений: авто / только вручную / выключено.
- ☑ 4.6 Статистика (только счётчики, без слов).
- ☑ 4.7 Настройки: боковая навигация вместо 10+ вкладок.
- ☑ 4.8 Синхронизация: слияние списков слов, старт/стоп без перезапуска,
  флаг «включено» не синхронизируется.
- ☑ 4.9 Обновления: реальная проверка версии по фиду из Info.plist;
  без настроенного фида проверка выключена.

## Этап 5. Инженерный долг
