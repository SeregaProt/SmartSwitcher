# ADR-0002: Вставка текста через keyboardSetUnicodeString

Дата: 2026-06-13. Статус: принято.

## Контекст
Перенабор слова можно делать: (а) реальными кейкодами после смены раскладки,
(б) синтетическими событиями с явной unicode-строкой, (в) через буфер обмена.

## Решение
Вариант (б): `CGEvent(keyboardEventSource:virtualKey:0)` +
`keyboardSetUnicodeString`, чанки ≤16 UTF-16 юнитов, пауза ~1,2 мс между
чанками, посылка в `cghidEventTap`. Каждое событие помечается маркером
`eventSourceUserData = 0x534D5357` («SMSW»), и собственный tap такие события
игнорирует (защита от самозацикливания).

## Альтернативы
- Кейкоды после смены раскладки — гонка: `TISSelectInputSource` применяется
  асинхронно, часть символов может набраться старой раскладкой.
- Буфер обмена — разрушает содержимое clipboard пользователя и истории.

## Последствия
- (+) Результат не зависит от активной раскладки и порядка переключения;
  проверено E2E-тестом (ghbdtn → привет в NSTextView).
- (−) Приложения, игнорирующие unicode-поле событий (некоторые игры,
  виртуальные машины), получат мусор — смягчается белым списком приложений.
