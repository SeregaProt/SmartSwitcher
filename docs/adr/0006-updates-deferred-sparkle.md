# ADR-0006: Обновления — Sparkle отложен до фазы релиза

Дата: 2026-06-13. Статус: принято (пересмотр в фазе 4).

## Контекст
ТЗ (раздел 14) требует Sparkle: appcast, EdDSA-подпись, каналы стабильный/бета.
Для работоспособной интеграции нужны: хостинг appcast-фида, ключи EdDSA,
подпись Developer ID (сейчас сборка ad-hoc, доменов и сайта нет).

## Решение
До фазы 4 — `UpdateService`-заглушка: пункт меню «Проверить обновления…»
открывает страницу релизов. Интерфейс сервиса изолирован, замена на Sparkle
не затронет UI.

## План интеграции Sparkle (фаза 4)
1. Зависимость SPM `sparkle-project/Sparkle` (MIT).
2. Генерация EdDSA-ключей, `SUPublicEDKey` в Info.plist.
3. Appcast на сайте + nightly-канал для беты (ТЗ 16).
4. Подпись Developer ID + нотаризация — обязательное условие.
