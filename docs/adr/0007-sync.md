# ADR-0007: Синхронизация настроек через iCloud KVS

Дата: 2026-06-13. Статус: принято.

## Контекст
ТЗ (раздел 15) требует синхронизации настроек и правил между устройствами;
только настройки, никогда — набранный текст или история. Разрешение
конфликтов — last-write-wins.

## Решение
`NSUbiquitousKeyValueStore` (iCloud key-value). Хранится один снапшот
конфигурации (тот же `ImportExportService.Snapshot`, что и для экспорта) +
временная метка. Конфликты — last-write-wins по метке. Дневник и любой текст
ввода в KVS не попадают (в Snapshot их нет).

## Почему KVS, а не CloudKit
Объём настроек крошечный (< 10 КБ), KVS проще, не требует схемы и работает
оффлайн с авто-слиянием. CloudKit избыточен для key-value конфигурации.

## Зависимость от подписи
KVS работает только с entitlement
`com.apple.developer.ubiquity-kvstore-identifier`, который активируется при
подписи Developer ID с провижнинг-профилем. В dev-сборке (ad-hoc) вызовы KVS
безопасно ничего не делают — `SyncService` корректно деградирует, локальные
настройки и ручной экспорт/импорт работают всегда. Включение — тумблером
«Синхронизировать через iCloud» (по умолчанию выкл).

## Защита от циклов
Локальное изменение → отложенный (1.5 с) push; внешнее изменение применяется
под флагом `isApplyingRemote`, подавляющим обратный push.
