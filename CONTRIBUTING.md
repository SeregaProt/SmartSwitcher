# Контрибьюция в SmartSwitcher

Спасибо за интерес к проекту! Ядро открыто (MIT, open-core модель — ТЗ 22/25).

## Быстрый старт

```bash
make build   # сборка (Swift 5.9+/6, достаточно Command Line Tools)
make test    # обязательный набор проверок и метрик качества
make run     # собрать .app и запустить
```

## Правила

- **Ветвление**: `main` — релизный, работа в feature-ветках, PR с зелёным CI.
- **Версионирование**: SemVer; изменения — в CHANGELOG.md (Keep a Changelog).
- **Каждый PR, меняющий поведение, обновляет документацию** (README, docs/,
  ADR при архитектурных решениях) — проверяется на ревью (ТЗ 17).
- **Тесты обязательны** для Core и Brain. Детекторные изменения должны
  проходить оценочный стенд: recall > 90%, ложные срабатывания на редких
  словах < 2%, на частотных — 0 (ТЗ 7.2, 16).
- **Приватность — неприкосновенна**: запрещено логировать или передавать
  набранный текст. PR, нарушающий это, не будет принят ни под каким предлогом.

## Стиль кода

- Swift API Design Guidelines; комментарии — только о неочевидных контрактах.
- Пользовательские строки — через `L10n.text(key, fallback)` с переводом
  в обоих `.lproj`.
- Системные API изолируются в своих модулях (Core/Infrastructure), логика —
  чистая и тестируемая.
